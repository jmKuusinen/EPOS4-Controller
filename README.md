# EPOS4-Controller
Software for EPOS motor-controller

This is a hobby project intended to be used with EPOS4 dc-motor controller, Maxon dc-motor and a third motor.  Maxon motor acts as a load motor for [Device under test] third motor. 

This source code isn't actively maintained, but there are numerous improvements in the works.

You will need to download EposCmd.Net and EposCmd64.dll libraries for program to work.

PIP-packages: {
    pythonnet,
    PIL
}
