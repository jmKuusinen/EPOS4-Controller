# EPOS4-Controller
General software for dc-motor control with epos. 

This is a project intended to be used with EPOS4 dc-motor controller, load motor & DUT- motor.
This source code isn't actively maintained, but there are numerous improvements in the works.

You will need to download EposCmd.Net and EposCmd64.dll libraries for program to work.

PIP-packages: {
    pythonnet,
    PIL
}
